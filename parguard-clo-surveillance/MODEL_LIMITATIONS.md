# Model Limitations

- The model uses synthetic illustrative data.
- It does not replace a trustee report.
- It does not model full CLO indenture mechanics.
- It is not a rating, valuation, investment recommendation, or legal analysis.
- Actual CLO transaction terms differ materially and must be reviewed by qualified users.
- PDF extraction is limited to text-based PDFs and returns unverified candidate values only; it does not perform OCR or production document parsing.
