# 5–7 Minute Demo Script

1. Start at **Deal Overview**. “ParGuard is a local deterministic CLO surveillance application using synthetic collateral and liabilities.”
2. Explain the pool and capital stack. “The app loads the active deal, as-of date, collateral pool, and tranche stack from CSV/JSON inputs.”
3. Show base-case status. “In base case, the model displays OC and IC tests with numerator, denominator, trigger, actual ratio, cushion, and formula.”
4. Identify closest test. “The Analyst Morning Brief calls out the closest coverage test to breach and the next analytical question.”
5. Enter **Collateral Surveillance**. “Here I review collateral-quality tests, concentration tables, watchlist/default heatmaps, and top obligors.”
6. Select **CCC Migration Shock**. “This deterministic stress migrates weaker loans into CCC, exceeds the configured CCC limit, applies excess-CCC treatment, and reduces adjusted collateral.”
7. Open **Scenario Comparison**. “The OC deterioration bridge decomposes adjusted-par change into default/recovery effects, CCC treatment, scenario haircuts, price treatment, and other adjustments.”
8. Enter **Cash Flow Waterfall**. “When coverage tests fail, residual interest that would otherwise reach equity is diverted to debt paydown in this simplified model.”
9. Open **Surveillance Memo & Exports**. “The memo can be exported as Markdown or HTML, with supporting CSV and JSON model outputs.”
10. Finish honestly. “This is an educational simplified model, not a trustee report, legal interpretation, rating, valuation, or investment recommendation.”
